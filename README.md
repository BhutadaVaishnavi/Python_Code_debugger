# AI Debug Assistant

This is a simple Python project that helps you debug code using AI. It takes your Python code and error message as input and gives back a clear explanation along with the corrected code.
The project uses the Hugging Face API and is built with Python, requests, and python-dotenv. It runs in the terminal, so you can easily use it in VS Code.
To run the project, clone the repo, install the required libraries, and create a `.env` file with your Hugging Face API token. Then run `python app.py` and paste your code and error when prompted.
Make sure not to upload your `.env` file since it contains your API key.
This project is great for beginners and can be extended further by adding a UI or automating error detection.
